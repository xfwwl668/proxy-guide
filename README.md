## 3 步上手（通用流程）

1. **部署**：按上面表格进对应教程，拿到**订阅链接**
2. **导入**：装客户端，把订阅链接导进去 —— [客户端使用教程](docs/07-客户端使用-订阅导入.md)
3. **验证**：确认真的能用 —— 同上文档最后一节，别跳过

## ⚠️ 动手前的 5 条提醒

1. **密钥别公开**：UUID、BOT_TOKEN、哪吒 KEY、Argo 凭据，只填在平台的环境变量里，**别提交到公开仓库**。
2. **免费平台有代价**：会回收、会限速、规则随时变，重要用途别只依赖免费。
3. **遵守平台条款**：部署前看一眼平台 ToS，被删号别意外。
4. **别信"绝对"的说法**：没有"全支持""最强""不会被墙"的方案，网络环境天天变，教程里凡是这种词我都改掉了。
5. **连不上先查排错手册**：[docs/08](docs/08-排错手册.md)，90% 的问题都在里面。
