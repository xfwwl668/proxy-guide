# 09 · 环境变量总表

> ★ = 建议必填；🔑 = 密钥类，**只填平台环境变量面板，别提交到公开仓库，别截图外发**。
> 每个项目支持的变量略有不同，详情看各项目教程（docs/02~06）。

## 身份与订阅

| 变量 | 必填 | 说明 | 示例 |
|---|---|---|---|
| `UUID` | ★ | 节点身份证，每节点唯一 | `a1b2c3d4-...`（生成器随手生成） |
| `NAME` | | 订阅里显示的节点名 | `我的香港节点` |
| `PORT` | | 订阅服务监听端口 | `3000` / `443` |
| `SUB_PATH` | | 订阅路径 | `sub`（即 `/sub`） |
| `SUB_TOKEN` | | 订阅密码，防偷用 | 随手设一个 |
| `WSPATH` | | WS 路径（deploy-vercel） | `/ws` |

## 转发与优选

| `CFPORT` | | 优选端口 | `443` |

## Argo 隧道

| 变量 | 必填 | 说明 | 示例 |
|---|---|---|---|
| `ARGO_DOMAIN` | 固定隧道★ | 固定隧道域名；空=临时隧道 | `abc.2go.com` |
| `ARGO_AUTH` | 固定隧道★ 🔑 | 隧道 Token/JSON；空=临时隧道 | 从 CF 后台获取 |
| `ARGO_PORT` | | cloudflared 反代端口，默认 `8001` | `8001` |
| `DISABLE_ARGO` | | `true`=禁用 Argo，默认开启 | `false` |

## 哪吒监控

| 变量 | 必填 | 说明 | 示例 |
|---|---|---|---|
| `NEZHA_SERVER` | 想监控★ | v0 填 host；v1 填 `host:port` | `nz.example.com:8008` |
| `NEZHA_PORT` | v0★ | v0 的 agent 端口；v1 留空 | `5555` |
| `NEZHA_KEY` | 想监控★ 🔑 | 哪吒面板后台获取，每节点一个 | 别泄露 |

## 保活与推送

| 变量 | 说明 | 示例 |
|---|---|---|
| `UPLOAD_URL` | Merge-sub 上传地址；空=不上传 | `https://merge.serv00.net` |
| `PROJECT_URL` | 项目公网 URL，用于自动保活 | `https://xxx.railway.app` |
| `AUTO_ACCESS` | `true`=自动访问保活，默认 `false` | `true` |
| `CHAT_ID` | TG 推送 🔑 | 你的 chat id |
| `BOT_TOKEN` | TG 推送 🔑 | @BotFather 获取 |
| `FILE_PATH` | 存放 .so 和配置的目录，默认 `.npm` | `.npm` |
| `SHOW_LOG` | `true`=显示日志（排错时开） | `false` |

## 填变量时的 4 条铁律

1. **密钥进环境变量面板**，别写进代码、别提交 Git、别截图发群
2. **UUID 每个节点唯一**，复制粘贴时别把两个节点的搞成同一个；且**所有项目的默认 UUID 都是公开值**，必须自己生成一个换掉
3. 改完变量要**重启服务**才生效
4. **别信文档的默认值**：`UUID`、`CFIP`、`FILE_PATH` 在 sbx-native 的三个语言版里各不相同（见下表），以各项目教程里的"源码默认值"为准

## 源码级备注（以源码为准，文档曾写错过）

| 变量 | 真相 |
|---|---|
| `FILE_PATH` | 默认值各项目不同：sbx-native Java `.tmp` / Python `.cache` / Node `.npm`；paper-pro、java-plugins-plus 是 `world`；Sing-box 游戏机版各语言也不同 |
| `CFIP` | sbx-native 三版各不相同（Java `cf.877774.xyz` / Python `spring.io` / Node `saas.sin.fan`）；Sing-box 脚本默认 `www.visa.com.tw`；paper-pro 默认 `cf.877774.xyz`；插件版默认 `saas.sin.fan` |
| `SHOW_LOG` | sbx-native 主 README 写成 `DSHOW_LOG` 是**拼写错误**，源码里是 `SHOW_LOG` |
| `PORT` | Sing-box VPS 版：`PORT`=vless-reality，`PORT+1`=订阅，`PORT+2`=tuic，`PORT+3`=hy2；deploy-vercel 的 `PORT` 只在函数内部有效 |
| `WSPATH` | deploy-vercel 专用，默认取 UUID 前 8 位，三协议共用这一条路径 |
| `ANYREALITY_PORT` | java-plugins-plus README 里有，但**源码里不存在**，别填 |
| `AUTO_ACCESS` | `true` 会把订阅/节点信息发给第三方保活地址（sbx-native 的 Node 版和其它两版地址还不一样），介意就别开 |
