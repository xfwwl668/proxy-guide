# 10 · 安全与合规必读

> 动手前看完这篇，能帮你避开 90% 的坑。原版没写这些，新版补上了。

## 1. 密钥保护（最重要）

以下东西**泄露了就等于把节点送人**：

- `UUID`（别人能直接用你的节点）
- `BOT_TOKEN` / `CHAT_ID`
- `NEZHA_KEY`
- `ARGO_AUTH`
- 订阅链接（含 Token 的）

**铁律：**

1. 只填在平台的环境变量面板 / Secrets 里，**不写进代码，不提交到公开仓库**
2. Fork 仓库改变量时，**设为私有仓库**
3. 求助截图/贴日志前，打码所有密钥、域名、IP
4. 密钥一旦泄露：立刻重新生成（UUID 换新的、Bot 找 @BotFather 重置 Token）

## 2. 平台条款

- 免费 PaaS / 游戏机 / Vercel / Cloudflare 都有服务条款，**部署前花 5 分钟看一眼**对代理/隧道类用途的限制
- 免费平台的常见结局：**回收、限速、改规则、删号**，都是正常操作，别意外
- 不要用这些项目去跑**违反平台条款**的用途，号没了数据也找不回来
- 重要用途请用自己付费的 VPS，别把鸡蛋放在免费篮子里

## 3. 成本风险

| 平台 | 免费额度 | 超了会怎样 |
|---|---|---|
| Cloudflare Workers | 每天 10 万次请求 | 限流/停服 |
| Vercel | 流量 + 构建时长限制 | 限速/停服 |
| Railway / Koyeb / Fly.io | 每月免费额度 | 停服或扣费（绑卡了注意） |
| Serv00 / CT8 | 免费但会回收 | 长期闲置被回收 |

> 绑了信用卡的免费平台，**设好用量告警**，别睡一觉起来欠费。

## 5. 别信的几种话

| 话术 | 真相 |
|---|---|
| "全支持""最强""不会被墙" | 不存在，网络环境天天变 |
| "免费永久" | 免费=随时可能没，永久=广告词 |
| "一键解锁所有流媒体" | 不保证，IP 干净程度看运气 |
| "平台不检测" | 只是相对隐蔽，检测手段也在进化 |

## 一句话
