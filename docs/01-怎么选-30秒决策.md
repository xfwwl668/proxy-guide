# 01 · 怎么选：30 秒决策

> 按顺序回答，第一个"是"就是你的答案。

## 决策树

```
你有 VPS（买的服务器）吗？
├─ 有 → Sing-box 一键脚本（docs/02）⭐ 最省心
└─ 没有 ↓
   你有免费游戏机（Serv00 / CT8 / Hostuno）吗？
   ├─ 有 → 有 MC 服务器且不想动主文件？
   │         ├─ 是 → java-plugins-plus 插件版（docs/05）
   │         └─ 否 → paper-pro 主文件版（docs/04）
   └─ 没有 ↓
      你有免费 PaaS（Railway / Koyeb / Fly.io）吗？
      ├─ 有 → sbx-native（docs/03），想要隐蔽选它
      └─ 没有 → 只想白嫖、能折腾反代？
                ├─ 是 → deploy-vercel（docs/06）
                └─ 否 → 回去搞一台 VPS 或游戏机，没有免费午餐
```

## 对比表

| 项目 | 难度 | 部署耗时 | 花钱吗 | 适合谁 |
|---|---|---|---|---|
| Sing-box 一键脚本 | ⭐ | 几分钟 | VPS 要钱 | 新手，有 VPS/游戏机 |
| sbx-native | ⭐⭐ | 几分钟 | 免费额度内不花钱 | 有免费 PaaS，想要隐蔽 |
| java-plugins-plus | ⭐⭐ | 约 2 分钟构建 | 免费 | 有 MC 服务器，不想动主文件 |
| paper-pro | ⭐⭐⭐ | 7~10 分钟构建 | 免费 | 有游戏机，想防回收 |
| deploy-vercel | ⭐⭐⭐ | 十几分钟 | 免费额度内不花钱 | 能折腾 CF Worker 反代 |

## 难度说明

- ⭐：复制粘贴一条命令就行
- ⭐⭐：改几个环境变量，上传文件
- ⭐⭐⭐：要 Fork 仓库、等 GitHub Actions 构建、再配反代，步骤多但跟着走就行

## 给新手的建议

1. **第一次玩，直接选 Sing-box**（docs/02）。别贪多，先跑通一个。
2. **免费平台 = 随时可能没**：被回收、被限速、改规则都是常态，别把重要东西押在上面。
3. **一次只搞一个项目**，跑通、验证能用（docs/07 最后一节），再玩下一个。
