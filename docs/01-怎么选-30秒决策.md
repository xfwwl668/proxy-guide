# 01 · 怎么选：30 秒决策

> 按顺序回答，第一个"是"就是你的答案。

## 决策树

```
你有 VPS（买的服务器）吗？
├─ 有（且有 root）→ Sing-box 一键脚本 VPS 版（docs/02）⭐ 最省心
└─ 没有 ↓
   你有免费主机（Serv00 / CT8）吗？
   ├─ 有 → Sing-box 一键脚本 Serv00 版（docs/02），记得手动改 UUID 和 tuic 密码
   └─ 没有 ↓
      你在开 MC 服务器吗？
      ├─ 在开，且不想换主文件 → java-plugins-plus 插件版（docs/05）
      ├─ 在开（Paper 系），接受换主文件 → paper-pro 主文件版（docs/04）
      └─ 没开 ↓
         你有免费 PaaS（Railway / Koyeb / Fly.io）吗？
         ├─ 有 → sbx-native（docs/03），Java 版最稳
         └─ 没有 → 只想白嫖、能折腾反代？
                   ├─ 是 → deploy-vercel（docs/06），接受纯 WS、无 UDP
                   └─ 否 → 回去搞一台 VPS 或游戏机，没有免费午餐
```

> 💡 冷知识（源码证实）：`sbx-native`、`paper-pro`、`java-plugins-plus` 是**同一套代码的三种投递方式**（独立进程 / 编译进服务端 / 做成插件），功能一样，选哪个只看你手里有什么。详细对比见 [docs/12](12-五项目源码级对比.md)。

## 对比表

| 项目 | 难度 | 部署耗时 | 花钱吗 | 适合谁 |
|---|---|---|---|---|
| Sing-box 一键脚本 | ⭐ | 几分钟 | VPS 要钱 | 新手，有 VPS/免费主机 |
| sbx-native | ⭐⭐ | 几分钟 | 免费额度内不花钱 | 有免费 PaaS，选 Java 版 |
| java-plugins-plus | ⭐⭐ | 约 2 分钟构建 | 免费 | 有 MC 服务器，不想动主文件 |
| paper-pro | ⭐⭐⭐ | 7~10 分钟构建 | 免费 | 从零搭 Paper 服 |
| deploy-vercel | ⭐⭐⭐ | 十几分钟 | 免费额度内不花钱 | 能折腾 CF Worker 反代，接受纯 WS |

## 难度说明

- ⭐：复制粘贴一条命令就行
- ⭐⭐：改几个环境变量，上传文件
- ⭐⭐⭐：要 Fork 仓库、等 GitHub Actions 构建、再配反代，步骤多但跟着走就行

## 给新手的建议

1. **第一次玩，直接选 Sing-box**（docs/02）。别贪多，先跑通一个。
2. **免费平台 = 随时可能没**：被回收、被限速、改规则都是常态，别把重要东西押在上面。
3. **一次只搞一个项目**，跑通、验证能用（docs/07 最后一节），再玩下一个。
