# 08 · 排错手册

> 连不上别慌，按症状往下查。90% 的问题都在下面。

## 节点连不上 / 全部超时

1. **服务端还活着吗**：浏览器打开订阅链接，能看到节点信息=活着；打不开=服务端挂了，先修服务端
2. **换网络试试**：WiFi 和手机流量各试一次，排除本地网络问题
3. **换节点试试**：测速，选延迟最低的；都超时就是服务端/网络问题
4. **订阅过期了**：订阅 → 更新所有订阅，节点信息可能变了
5. **客户端版本**：升级到最新版，旧版本可能不支持新协议

## 延迟高

1. 换延迟最低的节点
2. 换协议试试：弱网环境可以试 HY2 / TUIC（UDP 系）；求稳试 VLESS Reality
3. 换优选域名：访问优选订阅站（原版用 `https://sub.eooce.xx.kg`，如果打不开就换别的优选源），挑延迟低的填进 `CFIP`
4. 换服务器地区：选离你近的（亚洲选日韩新）
5. 高峰期（晚上）延迟高是正常的，换个时间再试

## 能连上但打不开网页

1. 检查代理模式：PAC 切全局试试
2. 检查系统代理是否启用
3. 浏览器代理设置：用系统代理或自动检测
4. 检查节点详情：地址、端口、UUID、协议、TLS 开关、SNI、路径，一个个对
5. DNS 泄漏：做一次 DNS leak test，确认解析走的不是本地运营商

## 哪吒面板不显示节点

1. `NEZHA_SERVER` 填对了吗？
   - v0：填 host（如 `nz.example.com`），`NEZHA_PORT` 填 agent 端口（如 `5555`）
   - v1：填 `host:port`（如 `nz.example.com:8008`），`NEZHA_PORT` 留空
2. `NEZHA_KEY` 对吗？去哪吒面板后台复制，别手打
3. TLS 自动检测：哪吒端口是 443 / 8443 / 2096 / 2087 / 2083 / 2053 时自动开 TLS，其他端口不开——端口和实际对不上就连不上
4. 不同节点的备注（tag）要不同，不然面板里分不清

## 反代后打不开（deploy-vercel / CF Worker）

1. Worker 部署成功了吗？直接访问 Worker URL，看能不能打开伪装网页
2. 反代代码里的 Vercel 域名填对了吗
3. 自定义域名 DNS 记录加了吗
4. 反代域名如果被墙，换个 Worker 域名或换自定义域名，重新部署

## Argo 隧道相关

1. 用临时隧道：每次重启域名会变，订阅要重新更新
2. 用固定隧道：`ARGO_DOMAIN` + `ARGO_AUTH` 都要填对，缺一个就不通
3. `DISABLE_ARGO=true` 会关掉 Argo，确认你不是误开了这个

## TG 推送没消息

1. `BOT_TOKEN` 对吗？找 @BotFather 重新核对
2. `CHAT_ID` 对吗？给 Bot 发句话再查
3. 两个都填了才推送，缺一个就没动静

## 还是不行？

1. 把服务端的日志打开（`SHOW_LOG=true`），看报错信息
2. 带着这三样去问人：你用的哪个项目、哪一步卡住、日志/截图（**记得打码 UUID、Token、KEY、域名**）
