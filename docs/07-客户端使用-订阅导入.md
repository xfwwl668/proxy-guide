# 07 · 客户端使用：订阅导入（以 V2RayN 为例）

> 不管你部署的是上面哪个项目，最后都是这一步：把订阅链接导进客户端，连上就能用。

## 准备什么

- [ ] 部署完成后拿到的**订阅链接**（如 `http://你的服务器:端口/sub`）
- [ ] 客户端软件：
  - Windows：**V2RayN**（本教程用它演示）
  - Android：v2rayNG / NekoBox
  - iOS：Shadowrocket / Stash / Streisand（付费较多）
  - 全平台：Mihomo / Clash 系

> ⚠️ 原版列了个 "Siri" 客户端，查不到对应产品，这里没收录。
> 客户端版本不同，协议支持也不同，导入前确认客户端支持你的协议。

## 操作步骤（V2RayN）

### 1. 安装

去 V2RayN 的 GitHub Releases 下载最新版，解压即用（Windows 免安装）。

### 2. 添加订阅

1. 打开 V2RayN → 顶部菜单 **订阅** → **订阅设置**
2. 点 **添加**，把订阅链接粘贴进去，备注随便写，确定
3. **订阅** → **更新所有订阅**（不通过代理更新也行，看你网络情况）

### 3. 选节点、测速

1. 订阅分组下出现节点列表
2. 选中一个节点，右键 → **测试服务器延迟**（或按 Ctrl+T 测全部）
3. 延迟能返回数字的就是通的，`超时`的就是不通，换一个

### 4. 设为系统代理

1. 双击节点（或右键设为活动服务器），托盘图标变色表示已启用
2. 系统托盘右键 V2RayN → **系统代理** → 选 **自动配置系统代理**（PAC）或 **全局**
   - 日常推荐 PAC（只让需要走的走代理）
   - 啥都打不开时切全局试试

### 5. 验证：确认真的可用（别跳过！）

做完上面不代表真的通了，按顺序验证：

- [ ] **IP 变了**：浏览器搜"我的 IP"，看显示的 IP / 归属地是不是变成了服务器所在地区
- [ ] **目标网站能开**：打开之前打不开的网站，能正常加载
- [ ] **DNS 没漏**：搜 "DNS leak test" 测一下，解析结果应该也是服务器地区的，不该是你本地运营商的
- [ ] **延迟可接受**：测速延迟 < 300ms 日常可用，> 500ms 考虑换节点/换优选

四个都过，才算"真的能用"。

## 订阅链接的格式

一般长这样：`http(s)://域名或IP:端口/sub`，有的带 Token：
`http://域名:端口/sub?token=xxx` —— Token 是订阅密码，别发给别人。

## 出问题怎么办

| 症状 | 先查 |
|---|---|
| 订阅更新后节点列表是空的 | 订阅链接在浏览器里能打开吗？先确认服务端没问题 |
| 所有节点都超时 | 换网络（WiFi/手机流量）试试；检查服务端是否在线 |
| 能连但打不开网页 | 检查是不是 PAC 模式问题，切全局试试；看 [排错手册](08-排错手册.md) |
| 提示协议不支持 | 客户端版本太旧，升级客户端 |

## 多设备用

订阅链接可以在手机、电脑上同时导入。但注意：
订阅 Token 别公开，谁拿到链接谁就能用你的节点、用你的流量。
